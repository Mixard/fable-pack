# fable-pack 2.0 (Phase 1) Implementation Plan

> **For agentic workers:** Execute this plan task-by-task (fresh subagent per task with review between tasks, or inline with checkpoints). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship fable-pack 2.0: remove model-known content, fix seven proven factual errors, split fable-knowledge into five domain plugins, align workflow skills with the 2026-09 harness, add parallel-plans, and migrate this server to the single-project (Replyvo app) profile.

**Architecture:** Marketplace repo `/root/fable-skills` (GitHub Mixard/fable-pack). Plugins live in `plugins/<name>/` with `.claude-plugin/plugin.json` and `skills/<skill>/SKILL.md` or `agents/<agent>.md`; `.claude-plugin/marketplace.json` declares them; `scripts/validate.py` enforces frontmatter, description ≤400 chars, marketplace consistency. Spec: `docs/specs/2026-09-01-fable-pack-2-design.md` (authoritative for content); audit: `docs/audits/2026-09-01-model-relevance-audit.md`.

**Tech Stack:** git, python3 (validate.py), Claude Code CLI 2.1.257 (`claude plugin …`, `claude -p`).
